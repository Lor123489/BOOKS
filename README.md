# مكتبة البيان — مشروع مكتبة نصية عربية مع MCP

مشروع بداية قابل للتشغيل محلياً، يتكون من:
- واجهة React عربية RTL: الرئيسية، فهرس الكتب، قارئ، بحث، مساعد المكتبة.
- خادم Express + SQLite FTS5 لفهرسة النصوص والبحث فيها.
- خادم MCP عبر Streamable HTTP على المسار `/mcp`.
- رفع كتب TXT وMD، مع تقسيمها إلى مقاطع قابلة للبحث والاقتباس.

## المتطلبات
- Node.js 20 أو أحدث
- npm

## التشغيل
1. انسخ `.env.example` إلى `.env`.
2. من مجلد المشروع نفّذ:
   ```bash
   npm install
   npm run dev
   ```
3. افتح الواجهة: http://localhost:5173
4. واجهة API وMCP: http://localhost:3001
5. نقطة MCP: http://localhost:3001/mcp

## إضافة كتاب
من الموقع افتح «إضافة كتاب»، ثم أدخل العنوان والمؤلف والتصنيف وارفع ملف `.txt` أو `.md`.
يمكن أيضاً وضع ملفات نصية في `data/books` ثم رفعها من لوحة الموقع.

### تنسيق النص الموصى به
استخدم عناوين واضحة، ويمكنك كتابة:
```
# اسم الكتاب
## الباب الأول
### الفصل الأول
النص...
[PAGE: 12]
نص الصفحة...
```
علامة `[PAGE: 12]` اختيارية، وتساعد على حفظ رقم الصفحة في نتائج البحث.
إذا كان المصدر ملف TXT بلا علامات صفحات، سيُحفظ المقطع مع رقم صفحة غير محدد؛ لا تخمّن أرقام الصفحات.

## أدوات MCP
- `search_library`: البحث في جميع الكتب وإرجاع مقاطع مع بيانات المصدر.
- `get_book`: جلب بيانات كتاب ومحتواه/مقاطع منه.
- `get_passage`: جلب مقطع محدد بواسطة معرّفه.

## ربطه بـ ChatGPT
MCP المحلي على `localhost` لا يكون متاحاً مباشرة من ChatGPT على الإنترنت.
للاتصال من ChatGPT تحتاج إلى:
1. نشر الخادم على استضافة تدعم Node.js مع HTTPS.
2. التأكد أن `https://YOUR_DOMAIN/mcp` متاح من الإنترنت.
3. إضافة خادم MCP في إعدادات التطبيقات/الموصلات في ChatGPT، إذا كانت ميزة إضافة موصلات MCP متاحة لحسابك.
4. استخدم عنوان MCP المنشور، وأضف المصادقة قبل إتاحة المكتبة للعامة.

لا تضع مفتاح OpenAI أو كلمة مرور قاعدة البيانات داخل الواجهة الأمامية. خزّن الأسرار في متغيرات بيئة الخادم.

## ملاحظة عن إجابات الذكاء الاصطناعي
الواجهة الحالية تعرض نتائج البحث النصي وتجهز API للمساعد. لتفعيل إجابات مولدة، أضف `OPENAI_API_KEY` في `.env` ثم يمكن توصيل مزود النموذج في `server/index.js`.
في الوضع الحالي لا تدّعي الواجهة أن الذكاء الاصطناعي قرأ كتاباً كاملاً؛ الإجابة يجب أن تستند إلى المقاطع المسترجعة وتذكر الكتاب والصفحة كما وردت في البيانات.

## تطوير الإنتاج
قبل النشر العام أضف:
- تسجيل دخول وصلاحيات لإدارة الكتب.
- حدّاً لحجم الملفات والتحقق من نوعها ومحتواها.
- نسخاً احتياطية لقاعدة البيانات والملفات.
- سياسة حقوق نشر: ارفع الكتب التي تملك حق نشرها أو التي يسمح ترخيصها بذلك.
- فهرسة أفضل للنص العربي (تطبيع الألف/الياء والتشكيل) حسب حاجتك.
